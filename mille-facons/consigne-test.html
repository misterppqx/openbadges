Mille façons de reconnaître : consigne pour les testeurs

22 novembre 2026

Pourquoi ce test

Nous vous demandons de repérer ce qui n’est pas clair, page par page, avant de diffuser le site dans les lycées agricoles et les MFR.

« Mille façons de reconnaître » est un mini-site destiné aux apprenants de l’enseignement agricole, de la 4e au BTS. Il sert de support à un atelier de découverte : d’abord réfléchir à la reconnaissance, puis découvrir les badges numériques, enfin passer à l’action.

Le test est fait uniquement par des adultes : enseignants, formateurs, CPE, maîtres de stage, documentalistes. Vous testez seul, ou vous servez de scribe pour un groupe d’apprenants.

Deux façons de tester

SeulScribe pour des apprenants
Qui navigueVousLes apprenants, ou vous en projetant le site
Qui remplit les retoursVousVous, avec leurs mots
Ce que vous notezCe qui vous gêne, en pensant aux apprenants que vous connaissezLeurs questions, leurs hésitations, les mots qu’ils ne comprennent pas, ce qui les fait réagir
Durée conseillée45 min à 1 h pour tout le site, ou 20 min pour un seul tempsUne séance d’atelier : environ 2 h 45, ou un seul temps sur une heure de cours

En scribe, notez de préférence leurs propres formulations, entre guillemets : « c’est quoi un endossement ? » nous apprend plus que « mot difficile ».

Pas à pas

  1. Ouvrez le lien de test dans un navigateur récent, sur ordinateur de préférence : https://misterppqx.github.io/openbadges/mille-facons/?test Gardez bien ?test à la fin : sans lui, le site s’ouvre normalement, sans outil de retour. Un bandeau « Mode test » en haut de l’écran confirme que vous êtes au bon endroit.
  2. Remplissez votre profil, une seule fois. Cliquez sur le bouton jaune « Avis sur cette page », en bas à droite, puis indiquez votre rôle et si vous testez seul ou comme scribe. En scribe, choisissez la formation des apprenants : le site adapte aussitôt ses exemples à leur niveau. Le nom de votre structure est facultatif.
  3. Parcourez le site comme le ferait un apprenant, dans l’ordre : Temps 1, Temps 2, puis Temps 3. Faites les activités : répondre aux questions, choisir, écrire.
  4. Sur chaque page, donnez votre avis dans le panneau : claire, moyennement claire ou pas claire.
  5. Signalez les passages pas clairs. Cliquez sur « Signaler un passage pas clair », puis touchez le passage dans la page : il se surligne en jaune. Écrivez ce qui coince dans le champ qui apparaît. Vous pouvez signaler plusieurs passages par page. Touche Échap pour annuler.
  6. Laissez un commentaire si vous le souhaitez : ce qui manque, ce qui gêne, ce qui marche bien.
  7. Téléchargez vos retours à la fin, avec le bouton « Télécharger mes retours (tableur) ». Vous obtenez un fichier .csv qui s’ouvre dans un tableur.

Vos retours sont gardés dans votre navigateur au fil du test : vous pouvez recharger la page, faire une pause et revenir plus tard sur le même ordinateur, avec le même navigateur. Pensez tout de même à télécharger avant de fermer définitivement.

Ce qui nous aide le plus

Ce que nous cherchons, c’est ce qui empêche un apprenant de comprendre ou d’avancer.

  • Les mots qu’un apprenant ne comprendrait pas, ou qui sont trop abstraits pour son âge.
  • Les consignes floues : on ne sait pas quoi faire, ni où cliquer.
  • Les exemples qui ne parlent pas à vos apprenants, ou qui ne correspondent pas à leur formation.
  • Les enchaînements : une notion qui arrive trop tôt, une page qui semble manquer, une répétition.
  • Ce qui marche bien : c’est utile aussi, pour ne pas le casser.

Inutile de corriger l’orthographe page par page : un commentaire suffit. Et si vous avez un doute sur le fond, sur la reconnaissance ou sur les badges, notez-le : c’est précisément ce que nous voulons savoir.

Données et confidentialité

Rien n’est envoyé sur internet : vos retours restent sur votre ordinateur jusqu’à ce que vous transmettiez vous-même le fichier.

  • Pas de nom : le fichier contient votre rôle, votre situation de test et, si vous la donnez, votre structure.
  • Pas de données d’apprenants : en scribe, ne notez ni nom ni information personnelle sur un jeune. Ce que les apprenants écrivent dans les activités du site n’est jamais mis dans le fichier de retours.
  • Sur un poste partagé : à la fin, après le téléchargement, cliquez sur « Tout effacer » dans le panneau pour ne rien laisser dans le navigateur.

Renvoyer vos retours

Envoyez le fichier .csv téléchargé, sans le modifier, à : acoustice@educagri.fr.

Gardez son nom d’origine (il commence par « retours-mille-facons- » suivi de la date) : il nous permet de distinguer les envois. Si vous testez plusieurs fois, envoyez un fichier par séance.

Une question, un souci technique (le bouton n’apparaît pas, le téléchargement ne marche pas) : écrivez à la même adresse.
